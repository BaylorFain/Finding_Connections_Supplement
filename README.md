## Introduction

This repository contains files to recreate and reproduce the figures and analyses in the manuscript:  
**Fain and Dobrovolny, (Submitted), "Finding Connections: A survey of within host viral dynamics modeling techniques"**

## Software Install

To recreate the plots in the figures, one only needs python. 
>[!NOTE]
>The provided plotting codes should work with current releases of _Python_ packages. 

To reproduce the data for the plots, one will need it install _CUDA_, _Python_, and _ollama_.
>[!NOTE]
>After the necessary software is installed, the codes provide will create the data for each plot

## Recreation

_Python_ is used to make the plots used in the manuscript. The data for each plot in a figure is provided and all that needs to be done is to run the provided code.
